# Student Management System (Java)

## Description
This is a console-based Student Management System developed using Java.
The project demonstrates the use of Object-Oriented Programming concepts
to manage student records efficiently.

## Features
- Add new student
- View all students
- Search student by ID
- Delete student
- Menu-driven console interface

## Technologies Used
- Java
- ArrayList
- Object-Oriented Programming (OOP)

## Project Structure
Student.java -> Student model class
StudentManager.java -> Handles operations on student records
Main.java -> Entry point of the application

## How to Run
1. Compile all `.java` files
2. Run `Main.java`
3. Use the menu to perform operations

## Sample Operations
- Adding student details
- Viewing student records
- Searching student by ID
- Deleting student records

## Purpose
This mini project was developed as part of the Winter Break Placement
Readiness Program to apply Java and OOP concepts in a practical way.
